# Repaster

Repasters is a hyper-local surplus food rescue platform connecting hotels, caterers, and food businesses directly with charities and community seekers. Featuring automated expiry protection, verified OTP coordination, and direct peer arrangement, it turns excess food into immediate community nourishment with zero middleman waste.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
